后端 `mvn spotless:check test` 使用 H2 MySQL 模式运行政策单元测试和 MockMvc 接口集成测试，固定时钟仅在测试注入，运行应用不提供修改时钟 API。测试密码每次随机生成，不记录或公开。

集成覆盖独立申请／复核／批准，管理员不能替代业务责任人；批准冻结、退回保留历史；草稿版本推进；SELF／部门和导出隔离；数量、对象版本与范围；相同 UUID 重试和变更冲突；重复使用凭据事务回滚；有效期首尾、上海午夜、365 日最大区间；撤销、调岗／禁用即时失效；并发登记只允许一次并不超量；CSRF 及最后管理员保护。

前端执行 format:check、lint、test、build，测试使用 Node 原生测试运行器，覆盖状态、显示规则、请求失败与 CSRF 封装。镜像构建重复以上必需检查，不设置跳过 Maven 测试选项。

真实环境使用全新独立 deviationflow-check MySQL 卷，运行 `python3 scripts/smoke.py` 创建明确 TEST 账号和台账，验证健康／登录／完整授权／部分使用／冲正／用尽／撤销、越权与重试。重启服务后 `python3 scripts/smoke.py --verify` 比对保存用量和历史。私有状态文件保存随机密码且被 Git 忽略，只用于本地验收；不能在客户或生产库运行。

浏览器另外验收多岗位操作、搜索与分页、详情和管理页面，在实际运行应用拍摄 README 图片。空库不生成样例记录。发布前运行 `python3 scripts/release-check.py`、检查 Git 差异和所有图片路径，核对原始 LOGO／微信二维码、授权文案、官网及联系方式。脚本敏感扫描只是辅助，人工审查仍必要。
